# Etapa A - Base tecnica y primer deploy

## Objetivo

Dejar el proyecto ejecutable, testeable y deployable con una SPA minima antes de implementar funcionalidades de negocio.

## Alcance incluido

1. Configuracion de React + TypeScript + Vite.
2. Scripts de desarrollo, build y testing.
3. Setup de Vitest + React Testing Library.
4. Aplicacion placeholder con estado de avance.
5. Configuracion de salida para Vercel.

## Criterio de cierre

1. `npm install` ejecuta sin errores.
2. `npm run dev` levanta correctamente.
3. `npm run test` pasa.
4. `npm run build` compila y genera salida de produccion.
5. Se publica una URL inicial en Vercel.
6. `README.md` queda actualizado con setup y alcance de etapa.

## Fuera de alcance

- Firebase Auth funcional.
- CRUD de tareas.
- Integracion AWS SES.
