# Plan de implementacion

Este directorio contiene el plan operativo del proyecto para avanzar por etapas deployables en Vercel.

## Estructura

- `tracker.md`: tablero de estado por etapa y checklist de la etapa activa.
- `etapa-a.md`: detalle ejecutable de la etapa en curso.

## Regla de avance

No se considera cerrada una etapa hasta completar los tres frentes:

1. Implementacion de alcance.
2. Tests automatizados en verde.
3. Actualizacion de documentacion en `README.md`.
